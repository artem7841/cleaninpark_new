ИНСТРУКЦИЯ: КАК ПОМЕНЯТЬ ФОТО НА САЙТЕ
======================================

После загрузки папки build на сервер фото можно менять без программиста.
Пересборка сайта не нужна — достаточно заменить файлы и при необходимости
отредактировать JSON-конфиги в папке build.


0. ПЕРВЫЙ РАЗ (перед сборкой сайта)
-----------------------------------

Если вы только настраиваете сайт, скопируйте текущие фото в папку public/images:

  Услуги (из src/assets):
    serv_1.jpg … serv_7.jpg, serv5.jpg  →  public/images/services/

  Галерея «До/После» (из src/assets):
    do1.jpg  →  public/images/portfolio/before/01.jpg
    posle1.jpg → public/images/portfolio/after/01.jpg
    do2.jpg  →  before/02.jpg, posle2.jpg → after/02.jpg
    … и так далее до 16-й пары

  Нижняя галерея:
    serv_1.jpg → public/images/portfolio/gallery/01.jpg
    serv_2.jpg → gallery/02.jpg
    serv_3.jpg → gallery/03.jpg
    serv_4.jpg → gallery/04.jpg
    serv_6.jpg → gallery/05.jpg

После этого выполните npm run build — все файлы попадут в папку build.


1. УСЛУГИ (блок «Наши услуги»)
------------------------------

Фото лежат здесь:
  build/images/services/

Файлы:
  serv_1.jpg, serv_2.jpg, serv_3.jpg, serv_4.jpg,
  serv_5.jpg, serv_6.jpg, serv_7.jpg

Как заменить фото:
  1) Подготовьте новое фото в формате JPG.
  2) Назовите его так же, как старый файл (например serv_3.jpg).
  3) Загрузите на сервер в папку build/images/services/ с заменой старого файла.
  4) Обновите страницу в браузере (Ctrl+F5).

Если нужно привязать другое имя файла к услуге — откройте файл:
  build/services.json

В каждой услуге есть поле "img", например:
  "img": "images/services/serv_3.jpg"

Измените имя файла в этом поле и сохраните JSON.


2. НАШИ РАБОТЫ (галерея на главной)
------------------------------------

Фото лежат здесь:
  build/images/portfolio/before/   — фото «До»
  build/images/portfolio/after/    — фото «После»
  build/images/portfolio/gallery/  — обычная галерея

Имена файлов: 01.jpg, 02.jpg, 03.jpg и т.д.

Как заменить фото «До/После»:
  1) Замените нужную пару файлов с одинаковым номером.
     Например: before/03.jpg и after/03.jpg — это один слайд.
  2) Обновите страницу (Ctrl+F5).

Как заменить фото в нижней галерее:
  1) Замените файлы в build/images/portfolio/gallery/
     (01.jpg, 02.jpg, 03.jpg …).
  2) Обновите страницу (Ctrl+F5).

Как добавить или убрать слайды:
  Откройте файл build/portfolio.json

  • beforeAfter — слайдер «До/После». Каждая строка — одна пара:
      { "before": "images/portfolio/before/01.jpg", "after": "images/portfolio/after/01.jpg" }

  • gallery — нижняя галерея. Список путей к файлам:
      "images/portfolio/gallery/01.jpg"

  Добавьте новую строку и положите соответствующий файл в нужную папку.
  Чтобы убрать слайд — удалите строку из JSON.


3. РЕКОМЕНДАЦИИ ПО ФОТО
-----------------------

  • Формат: JPG (можно также PNG — тогда измените расширение в JSON).
  • Размер: до 500 КБ на фото, ширина 1200–1600 px.
  • Для «До/После» используйте один и тот же ракурс и номер пары.
  • Перед правкой JSON сделайте копию файла на всякий случай.
  • После изменений проверьте сайт в режиме инкognito или с Ctrl+F5.


4. КОНТАКТЫ И РЕКВИЗИТЫ САЙТА
------------------------------

Откройте файл build/site.json

Раздел "contacts" — контакты:
  email              — почта
  phoneDisplay       — телефон как показывается на сайте
  phoneTel           — телефон для ссылок (только цифры, например +79956623002)
  phoneDisplaySecondary — второй телефон в подвале сайта
  phoneTelSecondary  — второй телефон для ссылки
  telegramUrl        — ссылка на Telegram
  whatsappUrl        — ссылка на WhatsApp

Раздел "company" — данные компании:
  brandName          — название бренда (CleanInPark)
  legalName          — ФИО для реквизитов
  inn                — ИНН
  founderName        — имя основателя на странице «О компании»
  founderRole        — должность основателя
  copyrightYear      — год в подвале сайта
  websiteUrl         — адрес сайта

Раздел "page" — заголовок и описание страницы в браузере:
  title              — заголовок вкладки
  description        — описание для поисковиков
  ogUrl              — адрес сайта для соцсетей

Раздел "map":
  yandexWidgetUrl    — ссылка на карту Яндекса

После изменений сохраните файл и обновите страницу (Ctrl+F5).


5. ГДЕ ЧТО ЛЕЖИТ В ПАПКЕ BUILD
------------------------------

  build/services.json          — тексты и фото услуг
  build/portfolio.json         — галерея «Наши работы»
  build/site.json              — контакты, ИНН, название компании
  build/images/services/       — картинки услуг
  build/images/portfolio/      — картинки галереи
